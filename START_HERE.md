# Стартовый запрос для Claude

Реализуй веб-приложение по этому комплекту документов. Цель — уровень max тестового задания: голосовой ввод, круговой прогресс, семантический анализ и генерация структурированного описания вакансии.

Сначала прочитай CLAUDE.md, docs/01-prd.md и docs/09-decisions.md. Затем прочитай docs/10-design-system.md и docs/11-interface-states.md, остальные документы, схемы и примеры. Проверь существующий репозиторий. Сохрани его рабочие функции и инструкции.

Составь короткий план. Затем приступи к реализации. Не ограничивайся планом или статичным макетом. Выполняй задачи из docs/07-plan.md по порядку. На каждом этапе запускай проверки, которые подтверждают поведение.

Стек по умолчанию: React, TypeScript, Vite, Carbon (@carbon/react), Node.js, Express, Zod, Vitest и Playwright. STT: Deepgram. LLM: Anthropic. Если готовый репозиторий требует другой стек, сохрани продуктовые требования и документируй замену.

Реализуй явные режимы demo и live. Demo нужен для воспроизводимой проверки без ключей. Live должен использовать настоящую запись, распознавание, анализ и генерацию. Не выдавай demo за рабочую AI-интеграцию.

Не задавай вопросы о мелких деталях. Принимай обратимые решения и записывай их. Если отсутствуют ключи, продолжай доступную работу. В отчёте укажи, какие реальные проверки заблокированы. Не утверждай, что live проверен, если запуск был только на фикстурах.

В конце дай команды запуска, результаты проверок, известные ограничения и сценарий демонстрации. Обнови README разработчика и docs/implementation-status.md. Не публикуй приложение и не отправляй материалы третьим лицам без отдельного поручения.

Обязательный дизайн: glassmorphism поверх Carbon с кастомизацией через токены. Только desktop; адаптация по ширине окна. Реализуй все нулевые, пустые, ошибочные и сетевые состояния. До полировки собери галерею состояний. Проверь потерю сети во время записи, обработки и генерации.

Отдельно прочитай docs/12-progress-animation.md. Это обязательная спецификация круговой анимации по референсу Apple Face ID. Обычного спиннера недостаточно: круг должен сохранять и постепенно показывать подтверждённый прогресс по ответам.
