# Автономная версия

## Что скачать

На странице [Releases](https://github.com/pakusdesign/test/releases) скачайте:

| Mac с Apple Silicon | Windows x64 |
|---|---|
| `vacancy-brief-macos-arm64.zip` | `vacancy-brief-windows-x64.zip` |
| `ggml-small.bin` | `ggml-small.bin` |
| `qwen3-4b-instruct.part-01` | `qwen3-4b-instruct.part-01` |
| `qwen3-4b-instruct.part-02` | `qwen3-4b-instruct.part-02` |
| — | `ollama-runtime-windows-x64.zip` |

Распакуйте архив приложения. Поместите остальные файлы в его папку `model-assets`. На Mac запустите `start.command`, на Windows — `start.cmd`. Откроется браузер на `http://127.0.0.1:3200`. Окно запуска держите открытым. Для микрофона разрешите доступ браузеру.

Скачивать файлы необходимо при наличии интернета. После этого приложение не загружает модели, не запрашивает ключи и не отправляет ответы в облако. Сервер и Ollama слушают только `127.0.0.1`. При первом запуске части модели собираются в локальный blob и проверяются по SHA-256. Понадобится около 7 ГБ свободного места с учётом скачанных частей, распакованных файлов и собранной модели.

Исходный архив GitHub (`Source code.zip`) содержит только код. Для работы без интернета используйте файлы выпуска. Windows x64 и Mac Apple Silicon — две отдельные сборки; Windows ARM и Intel Mac сейчас не поддерживаются.

## Как собран выпуск

Workflow `.github/workflows/offline-release.yml` запускается вручную с тегом выпуска. Он собирает приложение и зависимости для обеих систем, загружает проверяемые части моделей, создаёт архивы и публикует выпуск только после успешной сборки всех файлов. Интернет нужен только на этапе сборки. Приложение запускается через включённый Node.js; устанавливать Node.js, npm, Ollama или whisper.cpp пользователю не нужно.

Модель анализа: `qwen3:4b-instruct` через Ollama. Модель речи: многоязычная Whisper small через whisper.cpp. Описание вакансии составляется локальным шаблоном из подтверждённых фактов. Ограничения качества и проверки описаны в `docs/LOCAL-AI.md`.

## Проверка на другой машине

1. Скачайте все файлы выпуска на Mac с Apple Silicon и на Windows x64.
2. Отключите интернет до первого запуска.
3. Запустите соответствующий стартовый файл. Убедитесь, что `/api/config` показывает `mode: live`, `sttConfigured: true`, `llmConfigured: true`.
4. Запишите ответ голосом и проверьте распознанный текст. Проверьте текстовый ответ, подтверждение фактов и получение описания вакансии.
5. Перезапустите приложение без интернета и повторите проверку.

На Mac 4 ноября 2026 года проверен автономный пакет: распознавание тестового аудио вернуло HTTP 200 и русский текст; анализ четырёх ответов вернул HTTP 200 и шесть извлечённых фактов. На Windows x64 опубликованный пакет проверен в GitHub Actions: локальные STT и LLM запустились, речь была распознана, анализ вернул один факт. Проверка на личном компьютере с Windows ещё не проведена. Сборки не подписаны цифровой подписью, поэтому macOS или Windows могут показать предупреждение при первом запуске.
