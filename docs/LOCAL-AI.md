# Локальный анализ и описание вакансии

На Mac приложение использует whisper.cpp для распознавания речи и Ollama с моделью qwen3:4b-instruct для анализа текста. После проверки фактов документ собирается по шаблону из подтверждённых фактов. В интерфейсе источник результата указан как «Собрано по подтверждённым фактам».

Для самостоятельного запуска установите Ollama с https://ollama.com/download, выполните `ollama pull qwen3:4b-instruct` и запустите Ollama. В `.env` задайте `APP_MODE=live`, `LLM_PROVIDER=ollama`, `LLM_MODEL=qwen3:4b-instruct`, `PROVIDER_TIMEOUT_MS=120000`. Настройка whisper.cpp описана в docs/LOCAL-WHISPER.md. Затем запустите приложение через `npm run build` и `npm start`.

Первый полный анализ может занять больше минуты. В проверке четырёх ответов анализ занял 81 секунду, генерация шаблоном около 20 мс. Для одного ответа анализ занял 13 секунд. Модель иногда объединяет несколько сведений в один факт. Пользователь должен проверить и подтвердить факты перед генерацией. Проверка сервера отклоняет факты, чей текст не является дословным фрагментом цитаты ответа. Если модель не исправит вывод за две попытки, сервер вернёт INVALID_MODEL_OUTPUT.

Проверено через HTTP API: анализ произвольного текста и создание документа с пятью разделами. Проверено в Chrome: ввод нового ответа, успешный анализ, показ экрана проверки без ошибки JavaScript. Живой микрофон и качество на произвольных пользователях отдельно не оценивались. Это локальный прототип, а не гарантия качества для найма.
