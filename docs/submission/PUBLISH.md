## Запуск production

Используйте совместимый Node: 22.22.2+ в ветке 22, 24.15+ в ветке 24 либо 26+.

Отдельные команды: npm ci, npm run build, npm start. Сервер раздаёт клиент из dist/client. Для контейнера или хостинга задайте HOST=0.0.0.0, PORT по требованиям хостинга, APP_MODE=demo. Для микрофона на публичном адресе нужен HTTPS. Публичный demo не требует ключей AI.

Live требует DEEPGRAM_API_KEY, ANTHROPIC_API_KEY и совместимого LLM_MODEL. Храните их в серверном secret store хостинга. До публичного live проверьте ограничения запросов и доступ. Локальный прототип не заявляется production-ready.
