## Обновление: локальное распознавание, 4 ноября 2026

Подключён whisper.cpp v1.8.2 и многоязычная модель small. Deepgram больше не обязателен. Локальное распознавание проверено через HTTP API и запись из Chrome с синтетическим русским голосом. Текст виден в форме. Тишина даёт NO_SPEECH. На старых образцах espeak есть значительные ошибки распознавания; это ограничение зафиксировано. Живой микрофон вручную не проверен. Анализ и генерация через Anthropic остаются неподключёнными.

Проверки: 77 unit, 68 integration, 54 E2E. Исправлен замер контраста в E2E: сканирование ожидает завершения конечных анимаций, чтобы измерять установившийся цвет кнопки. Прежнее видео показывает demo и не является демонстрацией whisper.cpp. Инструкция: LOCAL-WHISPER.md; результаты: whisper-eval.json.
