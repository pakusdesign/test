# Световое кольцо 2.0 — материалы приёмки

Дата: 4 ноября 2026. Режим приложения: **demo**. Ответы — тестовые данные сценария «Сквозной сценарий с уточнением» и «Полный бриф». Звук микрофона — синтетическая речь `tests/evals/audio/fake-mic-q1.wav` (espeak) с добавленной паузой 1,8 с, подана через фиктивное устройство Chromium. MediaRecorder и Web Audio настоящие.

## Видео

| Файл | Что показывает |
|---|---|
| `acceptance.mp4` | Приложение целиком, 1440×900, 30 fps, 51 с: покой → запись q1 → недостаточный ответ (уточнение q1) → запись q2 при сохранённом предупреждении q1 → подтверждение q2 → уточнение q1 и подтверждение. Подписи этапов — в полосе под кадром. |
| `acceptance-ring-closeup.mp4` | Тот же проход, крупный план круга 2×: для сравнения характера света с референсным MP4 и формы ленты записи с изображением «01». |

Запись: Chromium 153 (Playwright 1.63.0) в окне приложения без интерфейса браузера, Xvfb, захват экрана ffmpeg x11grab 30 fps. Облачный Linux-контейнер без GPU.

## Кадры (deviceScaleFactor 2, окно 1440×900)

`01-pokoy`, `02-zapis`, `03-utochnenie`, `04-zapis-q2-pri-utochnenii-q1`, `05-100` — обычный режим; те же имена с `-reduced-motion` — prefers-reduced-motion: ровная лента вместо волн, статичная тёплая дуга, без перетекания и вибрации.

## Замер

`motion-metrics.json`. Кратко: отрисовка светового слоя — 3–5 ms на кадр при программной растеризации (до оптимизации — 19,6 ms). В контейнере без GPU страница с анимированным кругом держит около 28 fps, со статичным — 59 fps; без `backdrop-filter` стеклянной панели анимированный круг даёт 60 fps. Ограничение — программная перекомпоновка размытия стекла, а не код круга. На Mac (Chrome, Safari) замер не делался.
