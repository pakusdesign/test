# Сценарий демонстрации (5 минут)

Основан на разделе «Демонстрация на пять минут» в [08-acceptance.md](08-acceptance.md). Ключей нет, поэтому сценарий идёт в **demo**. Шаги, которые требуют live, помечены отдельно.

Подготовка: `npm ci && npm run dev`, Chrome, `http://127.0.0.1:5173`, разрешить микрофон. Сценарий в списке: «Сквозной сценарий с уточнением».

| Время | Шаг | Что показать и сказать |
|---|---|---|
| 0:00 | Начальный экран | Метка «Демонстрация» в шапке. Круг 0%, 64 штриха, четыре сектора. До нажатия микрофон не запрашивается. Сказать: «В demo ответы и анализ берутся из тестовых сценариев. Это не AI» |
| 0:30 | Вопрос 1 → «Записать ответ» | Ореол реагирует на голос, таймер идёт, процент стоит. «Завершить запись» → прослушать запись → «Подставить ответ сценария». Ответ помечен «Ответ из тестового сценария» |
| 1:10 | Факты | Один факт с цитатой-источником. Полнота всё ещё 0%: анализ сам прогресс не даёт. «Подтвердить сведения» → 8 штрихов сектора q1 проявляются по часовой стрелке за 400 мс, подпись 13% |
| 1:40 | Уточнение | «Какую ещё задачу он выполняет ежедневно?» Есть «Продолжить без уточнения». «Подставить ответ сценария» → второй факт → подтвердить → 25% |
| 2:10 | Вопросы 2–4 | «Ответить текстом», выбрать текст сценария, проверить и подтвердить. Сектора заполняются до 100%, затем появляется знак подтверждения |
| 3:00 | Обзор | Четыре карточки. Раскрыть факт «Проверять счета поставщиков.» и показать цитату, версию ответа и пометку «тестовый сценарий» |
| 3:30 | Описание | «Создать описание»: пять разделов, «Python желателен.» сохранён, блок «Нужно уточнить» (должность, условия). Зарплаты, стажа и формата работы нет |
| 4:00 | Правка и экспорт | Изменить заголовок → метка «Изменено вручную» → «Скачать .md» → `vacancy-description.md` |
| 4:30 | Документация | CLAUDE.md, `contracts/`, `docs/07-plan.md`, [docs/test-report.md](test-report.md), галерея `#/gallery` (S01–S26, N01–N10, стенд круга) |

Дополнительно (по вопросам):

- **Противоречие.** Сценарий «Противоречие в планах», вопрос 3 → S21 → исправить текст на «Продолжит платёжный модуль.»
- **Смена проекта.** На вопросе 2 подставить «Работает над CRM для отдела продаж…» → q2 и связанный q3 гаснут и требуют повторного подтверждения.
- **Сеть.** Во время записи отключить сеть (DevTools → Offline) → N02. Отправка → N03, запись сохранена. Включить сеть → N07 → «Повторить».
- **Честность demo.** Ввести произвольный текст → «В демонстрации нет анализа для этого текста».

## Live-версия (после подключения ключей)

Те же шаги, но с живой речью. Начните с неполного ответа («Проверяет счета поставщиков») — модель должна вернуть одну задачу, а интерфейс предложит уточнение. Затем вторая задача голосом. В шапке будет метка «Live». В шаге 6 сослаться на `docs/evidence/live-eval.json` с моделью, датой и результатами трёх прогонов. **Эта часть сценария не проверялась**.
