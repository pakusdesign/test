# План реализации для агента

Выполняй этапы последовательно. Не считай заглушку внешнего API завершённой live-интеграцией.

| Этап | Работа | Условие завершения |
|---|---|---|
| P0 | Прочитать репозиторий, создать журнал решений, выбрать версии | Зафиксированы структура, команды и зависимости |
| P1 | Создать приложение, сервер, схемы, фикстуры, demo-конфигурацию, подключить Carbon и токены | Приложение запускается одной командой; режим виден; основа Carbon работает |
| P2 | Реализовать чистые функции полноты и валидации источников | Проверены 0/50/100%, unknown, conflict, invalidation |
| P3 | Собрать текстовый путь через четыре вопроса и обзор | Можно исправить, подтвердить и пропустить ответ |
| P4 | Добавить MediaRecorder, визуализатор и STT | Проверены запись, отказ, stop, формат и реальный русский ответ |
| P5 | Подключить live-анализ, уточнения и подтверждение | Неполный ответ даёт правильное уточнение; источники валидны |
| P6 | Подключить генерацию, редактор и экспорт | Контрольный сценарий даёт фактическое описание |
| P7 | Добавить круг, glassmorphism, desktop-адаптивность и полную галерею состояний | Проверены DES01–DES06, S01–S26, N01–N10, MOT01–MOT12, reduced motion и клавиатура |
| P8 | Выполнить проверки, оформить README и демонстрацию | Есть отчёт с доказательствами и известными ограничениями |

## Ожидаемые команды готового репозитория

npm ci; npm run dev; npm run typecheck; npm run lint; npm test; npm run test:integration; npm run test:e2e; npm run eval:live; npm run build; npm start.

Это перечень отдельных команд, которые агент должен реализовать. Сейчас в комплекте нет package.json и эти команды не запускаются. npm run eval:live обращается к платным провайдерам; запускай его отдельно от обычного CI. Обычные тесты используют demo и заглушки сети.

## Статус и завершение

Для каждого этапа запиши: done / in_progress / blocked, доказательство, ограничения и следующий шаг. Если live заблокирован отсутствием доступа, заверши остальные этапы и ясно обозначь блокировку. Не ставь итоговую готовность max только по demo.

Минимальный финальный отчёт: что работает, как запустить, какие тесты выполнены, какие реальные провайдеры и браузеры проверены, что осталось, как показать решение за пять минут.

Дизайн выполняется по ходу реализации: в P1 заложи Carbon и токены; в P3 реализуй нулевые и пустые состояния; в P4–P6 добавь ошибки и восстановление сети вместе с соответствующими действиями. P7 завершает визуальную полировку и общую проверку. Не откладывай обработку ошибок до последнего этапа.

В P2 зафиксируй отображение восьми смысловых единиц на группы штрихов. В P4 добавь ореол от микрофона. В P7 заверши маски заполнения, прерывание переходов, галерею движения и замеры по docs/12-progress-animation.md.
