## Не выполнено: live и ручные проверки

1. `npm run eval:live`: 10 случаев × 3 прогона через Anthropic, генерация, STT на 5 синтетических примерах через Deepgram. Блок: нет ключей.
2. Проверка доступности модели из `LLM_MODEL` и поддержки ею structured outputs. Блок: нет ключа, модель не выбрана.
3. Реальная русская речь через микрофон в Chrome и Safari на macOS и запись версий браузеров. Блок: нет устройства в облачной среде.
4. Калибровка порога тишины и нормализации ореола на реальном микрофоне.
5. Smoke со screen reader (VoiceOver в Safari).
6. Запись производительности 10 с в Chrome и Safari на 60 Hz экране.
7. Обезличенные события этапов live с requestId, длительностью и моделью. Формат лога готов (`src/server/logger.ts`), реальных событий нет.

## Воспроизводимость

Проверено в чистой копии без `node_modules` (Linux, Node 22.23.4). На macOS `npm ci` установит платформенные бинарники (esbuild/rolldown, sass-embedded) для Mac; на машине разработчика этот шаг не выполнялся.

Команды для чистой копии:

```bash
npm ci
npm run typecheck && npm run lint && npm test && npm run test:integration
npx playwright install chromium && npm run test:e2e
npm run build && npm start
```
