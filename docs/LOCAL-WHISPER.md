# Локальное распознавание речи

Обновлено 4 ноября 2026 года. Приложение поддерживает whisper.cpp v1.8.2. Для русского языка используется многоязычная модель small (ggml-small.bin), без суффикса .en. Ключи Deepgram и Anthropic для распознавания не нужны.

## Как устроено

Браузер записывает аудио. При обычной остановке запись автоматически отправляется на сервер. После лимита или прерывания отправка происходит по кнопке. FFmpeg преобразует его в mono PCM WAV 16 kHz. whisper.cpp создаёт текст. Сервер возвращает текст в обычном контракте /api/transcribe с source=provider. Анализ и генерация по-прежнему используют Anthropic и требуют отдельного подключения. Demo всегда использует fixtures.

«Локально» означает на компьютере, где работает сервер приложения. Если сервер удалённый, запись передаётся на него. Данные не отправляются в облако распознавания. Временная папка доступна только владельцу; файлы удаляются после успеха, ошибки и отмены. Принудительное завершение сервера или отключение питания может оставить временные файлы в системном temp. Текст и аудио не пишутся в журнал сервера.

## Установка на другом компьютере

Нужны Git, CMake, C++ toolchain и FFmpeg. На macOS с Homebrew: `brew install cmake ffmpeg`. Затем:

```sh
git clone --depth 1 --branch v1.8.2 https://github.com/ggml-org/whisper.cpp.git
cd whisper.cpp
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j --config Release --target whisper-cli
bash models/download-ggml-model.sh small
```

В .env проекта укажите абсолютные пути:

```dotenv
APP_MODE=live
STT_PROVIDER=whisper
WHISPER_BINARY=/absolute/path/whisper.cpp/build/bin/whisper-cli
WHISPER_MODEL_PATH=/absolute/path/whisper.cpp/models/ggml-small.bin
FFMPEG_BINARY=/absolute/path/ffmpeg
STT_LANGUAGE=ru
```

Установите зависимости приложения (`npm ci`), соберите (`npm run build`) и запустите (`npm start`). Откройте http://127.0.0.1:3001. Для удалённого адреса нужен HTTPS, чтобы браузер разрешил микрофон. Модель и исполняемые файлы не входят в Git и архив исходников.

Прежний облачный адаптер сохранён: `STT_PROVIDER=deepgram`, `DEEPGRAM_API_KEY` и `STT_MODEL=nova-3`. Автоматического перехода на облако или demo нет.

## Ограничения и проверка

Одновременно выполняется одно локальное распознавание. Второй запрос возвращает RATE_LIMITED. Отмена и общий тайм-аут прекращают дочерний процесс. Ошибка декодирования даёт UNSUPPORTED_AUDIO, цифровая тишина — NO_SPEECH. Проверка энергии не является полноценным детектором речи: шум и неречевая запись могут дать ошибочный текст.

`npm run eval:whisper` выполняет реальные вызовы через HTTP API приложения без облачных ключей. Отчёт: docs/evidence/whisper/eval.json. Поле pass показывает работу транспорта, а не точность текста. Отдельная проверка qualityPassed сравнивает ключевые слова нового русского синтетического примера. Старые примеры espeak модель small распознаёт плохо; их нельзя считать доказательством качества. Нужен дополнительный ручной прогон с живым микрофоном.

Официальная документация: https://github.com/ggml-org/whisper.cpp/tree/v1.8.2.
