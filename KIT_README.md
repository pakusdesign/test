# Голосовой бриф вакансии — комплект для Claude

Версия: 1.2. Дата: 3 ноября 2026 года. Язык продукта: русский.
Статус: спецификация для реализации. Приложение ещё не создано. Проверки приложения ещё не выполнены.

## Результат

Веб-приложение задаёт четыре вопроса. Пользователь отвечает голосом или текстом. Система выделяет факты, показывает пробелы и предлагает уточнения. После проверки ответов система создаёт структурированное описание вакансии.

Комплект покрывает все три уровня задания. Он задаёт требования для уровня max. Оценку выставляет заказчик; комплект не гарантирует её.

## Как передать Claude

1. Скопируйте содержимое этой папки в репозиторий проекта. Сохраните существующие инструкции репозитория.
2. Откройте репозиторий в Claude Code или другом инструменте Claude с доступом к файлам и терминалу.
3. Передайте текст из [START_HERE.md](START_HERE.md).
4. Для настоящей обработки подключите серверные ключи STT и LLM. Не отправляйте ключи в чат.
5. После реализации проверьте [docs/08-acceptance.md](docs/08-acceptance.md).

Если Claude работает только в чате, приложите файлы. Для запуска кода потребуется отдельная среда разработки.

## Принцип текста

Используем русский язык с принципами упрощённого технического письма: короткие предложения, активный залог, один термин для одного понятия. Это адаптация стиля по запросу пользователя. Это не заявление о соответствии ASD-STE100 или измеренном соответствии на 80%.

## Изменения версии 1.1

По уточнению пользователя добавлены glassmorphism и компоненты Carbon с кастомизацией. Поддерживается только desktop с адаптацией к ширине окна. Мобильная версия исключена. Добавлена обязательная матрица состояний, включая потерю и восстановление сети. JSON-контракты остаются версии 1.0.

## Изменения версии 1.2

Добавлена отдельная спецификация анимации кругового индикатора. Зафиксированы 64 штриха, независимые группы полноты, движение при записи, ожидание, прерывания и доступность. Правила смысловой полноты и JSON-контракты не изменены.
