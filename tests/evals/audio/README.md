# Синтетические голосовые примеры для live-проверки STT

Созданы синтезатором espeak-ng (голос ru) и ffmpeg. Персональных данных и чужих голосов нет.

| Файл | Условие | Ожидание |
|---|---|---|
| quiet-q1.webm | Тихая комната, ответ на вопрос 1 | Есть «отказы оплаты», «конверсии» |
| quiet-q2.webm | Тихая комната, ответ на вопрос 2 | Есть «платёжным модулем» |
| noise-q1.webm | Ответ 1 с розовым шумом | Ключевые слова сохраняются или ошибку можно исправить |
| names-q4.webm | Названия SQL, Metabase, Python (произнесены по-русски) | Проверка распознавания названий; ошибки исправляются в расшифровке |
| silence.webm | 3 секунды тишины | NO_SPEECH, фактов нет |
| fake-mic-q1.wav | Источник для `--use-file-for-fake-audio-capture` Chromium | Ручная live-проверка записи без живого микрофона |

Синтетическая речь хуже живой. Результаты не заменяют ручную проверку с микрофоном в Chrome и Safari.
